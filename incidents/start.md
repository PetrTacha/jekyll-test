# Start

This project is markdown-first for content authoring.

## Local preview

```bash
bundle exec jekyll serve --force_polling
```

## Authoring quick rules

- Create docs as `.md` or `.markdown` files with front matter.
- Use `layout: page` for normal docs pages.
- Keep nav links in `/_data/navigation.yml`.
- Use GitHub alert syntax directly in markdown.

```md
> [!NOTE]
> Your note text here.
```
